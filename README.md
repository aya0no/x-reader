# X Reader PWA

`app.js` の `CONFIG.sections` にリストURLを追加してください。

GitHub Pages: Settings → Pages → Deploy from a branch → main / root → Save

## iPhone用Userscript

初回のみ、Safariで次のファイルを開き、Userscriptsの拡張メニューからインストールします。

[X Reader Userscriptを開く](https://raw.githubusercontent.com/aya0no/x-reader/main/x-reader.user.js)

以後はUserscriptsが更新を確認します。更新が表示されたら、Userscripts内の更新ボタンを押してください。

- 実行ファイル: `x-reader.user.js`
- 更新確認用: `x-reader.meta.js`

スクリプトを変更するときは、両方の `@version` を同じ値へ上げます。
